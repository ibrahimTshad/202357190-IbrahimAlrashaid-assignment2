# AI Usage Report

## Tools Used and Use Cases

I used ChatGPT as an AI-assisted development tool while completing this portfolio assignment. I used it in the following ways:

- Creating a starter HTML structure with About Me, Projects, and Contact sections
- Understanding the assignment requirements and organizing the required repository files
- Troubleshooting why the dark-mode button initially did not work
- Identifying incorrect CSS and JavaScript file names and folder paths
- Learning how CSS properties such as `width`, `height`, `max-width`, and `object-fit` affect images
- Adjusting project images so that they have consistent dimensions and remain responsive
- Reviewing the HTML structure and finding incorrectly nested or missing elements
- Improving project descriptions and preparing the README and this AI usage report

## Benefits

ChatGPT helped me break the assignment into smaller and clearer tasks. It provided examples that helped me understand how HTML connects to external CSS and JavaScript files. It also helped me diagnose visual problems more quickly, especially the dark-mode connection and the inconsistent project image sizes. The explanations allowed me to compare different CSS approaches and choose settings that fit my website.

## Challenges and Limitations

Some AI suggestions needed further testing and adjustment. For example, using `width: 100%` without first limiting the width of the project container caused an image to appear much larger than intended. Fixed image dimensions also behaved differently because the two project images had different aspect ratios. I needed to test the website in the browser, provide screenshots, and modify the suggested values before the layout looked correct.

The AI could not automatically know my preferred design or the exact dimensions of my images. Its output therefore served as guidance rather than a finished solution.

## Learning Outcomes

Through this process, I learned:

- How relative paths connect `index.html` to files inside `css`, `js`, and `assets` folders
- How CSS selectors target elements and how inline styles can override external stylesheets
- How `object-fit: contain` and `object-fit: cover` handle images with different aspect ratios
- How to use CSS Grid and Flexbox to create responsive project cards
- How JavaScript can change an HTML attribute to switch between light and dark themes
- How to inspect, test, and revise AI-generated suggestions instead of accepting them immediately
- How clear documentation helps other people understand and run a project

## Responsible Use and Modifications

I did not submit AI output without reviewing it. I tested the code in my browser, checked whether each feature worked, and changed image sizes, text, file paths, and layout rules based on the results. I replaced generic portfolio content with information about my own projects, including the five-stage pipelined CPU and the assignment tracker.

When a suggestion produced an image that was too large, I identified the problem through testing and revised the CSS. I also reviewed the HTML structure and corrected nested project elements. These modifications helped ensure that the final website reflects my own work and that I understand the code included in the submission.

AI was used as a learning and problem-solving aid. The final decisions, testing, modifications, and responsibility for the submitted work remain my own.
